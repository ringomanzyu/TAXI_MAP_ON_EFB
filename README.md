# TAXI_MAP_ON_EFB
フライトシミュレーターから現在地を取得し、外部タブレットなどで地上マップの表示及びナビゲーションを行うアプリケーションシステム
現時点ではMSFSのみの対応を予定
- iPadもしくはAndroidタブレットを標準でサポート、ほとんどの機器でネイティブ対応
- 将来的にはTAXI MAPだけでなく単体で動作するEFBとする。
## 実装予定のシステム
- 飛行場図/SID/STARの表示
- ルートの自動プランニング
- 到着空港の着陸前のプランニング
- NOTAMによる情報を取得し、自動的にクローズドのスポットとホールドポイントを避けるシステム
- 滑走路進入警告
- 外部アプリ/外部サイトではない機体での直接描画
- VATSIM/IVAOを利用中に、他機トラフィックを描画
